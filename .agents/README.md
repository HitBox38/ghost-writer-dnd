# Project skills

Selected by the user for the Ghost Writer D&D visual overhaul. Installed locally in `.agents/skills`; the original three skill folders were backed up before replacement. Exact upstream repositories, commit revisions, content hashes, and local adaptations are recorded in [skill-sources.json](skill-sources.json).

## Installed

- Taste: `brandkit`, `redesign-existing-projects`, `image-to-code`.
- Design: `impeccable`, `frontend-design`, `interface-design`, `ui-ux-pro-max`.
- Interaction: `emil-design-eng`, `prototype`, `mobile-native`, `review-animations`, `find-animation-opportunities`, `animate`.
- Engineering and accessibility: `vercel-react-best-practices`, `vercel-composition-patterns`, `web-design-guidelines`, `react-doctor`, `fixing-accessibility`.

## Runtime notes

UI/UX Pro Max includes its Python search scripts and data. Its command examples have been adapted from Claude plugin variables to absolute paths for this Windows project and Codex's bundled Python. The search command has been smoke-tested.

Impeccable includes its full references and Windows launcher. The launcher's version command has been verified. Its engine is cached through the upstream launcher.

Installation does not select a visual direction. Use the skills relevant to the current phase; broad design skills overlap, so the user's chosen brief should determine the result. No design artifacts, application changes, or automated design hooks were created by this installation.
